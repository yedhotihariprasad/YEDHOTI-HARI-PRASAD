# Hari Prasad Yedhoti — UI/UX Portfolio

A responsive static UI/UX portfolio website featuring four projects:

1. Temple History Exploring App
2. Grocery Shopping App
3. AI Talent Hiring Platform
4. Multi-Tenant Analytics Dashboard

## Run locally

Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select the main branch and `/root`.
5. Save and wait for the published URL.

## Before publishing

Replace:
- `your.email@example.com`
- `https://www.linkedin.com/`
- `https://github.com/`

with your real contact links.

The project links are already connected to the Figma URLs supplied for the portfolio.

## Figma embeds

Figma supports embedding prototypes in websites using an iframe. This version uses direct project links so the portfolio remains lightweight and reliable. If desired, the project pages can later be expanded with live Figma embeds.
